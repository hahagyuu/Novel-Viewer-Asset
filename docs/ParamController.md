# ParamController

シナリオの進行状況やフラグ、変数を一元管理するクラスです。

## 主な機能

- **変数管理**: 文字列キーで値を保持・取得します（例: `data["key"] = "value"`）。
- **スコープ制御**: 変数名の接頭辞（例: `l1`〜`l5`）によって変数の寿命（シナリオファイル内のみ有効など）を管理し、`ClearLevel` で一括消去が可能です。
- **セーブ＆ロード**: 現在の変数の状態を JSON ファイルに保存、または読み込みます。世代管理されたオートセーブ機能（`AutoSave_1.json` など）も備えています。

## 使い方

`ParamController.Instance.data["変数名"]` でアクセスします。
シナリオ内からは `FormulaEvaluator` 経由で間接的に値が読み書きされることが多いため、通常は直接スクリプトから呼び出すだけでなく、シナリオコマンド内で変数を操作します。
