# ScenarioPlayer

CSVからシナリオデータを読み込み、行ごとにコマンドを解釈して実行するメインスクリプトです。

## 主な機能

- **CSVパース・実行**: 各行のコマンド（キャラクター表示、スプライト変更、ジャンプなど）を順番に処理します。
- **UI管理**: テキストウィンドウ（`WindowEntry`）や選択肢ダイアログの表示制御を行います。
- **サブルーチン・ラベル機能**: `Jump`, `JumpSubroutine`コマンドによるシナリオファイルの柔軟な制御を実現します。
- **ログ機能**: 過去の会話を記録し、`logWindow`に表示可能です。

## 使い方

`ScenarioPlayer.Instance.Activate(scenarioFiles)` に `TextAsset` のリストを渡すことでシナリオの再生を開始します。
シナリオ再生中は、ユーザーのクリック入力またはアニメーションの完了を待機しながら自動的に行を進めます。
